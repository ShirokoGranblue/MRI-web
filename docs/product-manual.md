# 使用说明书

## 系统用途

医院核磁共振图像信息管理系统用于衔接患者资料、MRI 禁忌症、检查申请、检查排程、检查执行、影像归档、诊断报告和影像下载。系统分为医生端和患者端，两类用户看到的页面和可执行操作不同。

## 用户角色

- 医生：查看患者资料和禁忌症，处理检查申请和排程，复核检查风险，管理影像与报告，下载影像并查看下载记录。
- 患者：注册账号，维护本人资料和禁忌症，为本人提交检查申请，查看本人检查、影像和报告；报告发布后可查看和下载关联影像。

患者不能查看其他患者的数据。医生不能代替患者修改患者本人资料或禁忌症。

## 登录

医生使用预置账号：

```text
用户名：admin
密码：admin123
```

患者在登录页选择“患者注册”，填写姓名、用户名和密码。首次登录后需要先完成本人资料和 MRI 禁忌症登记。

登录状态失效时，页面会提示重新登录。当前账号没有某项操作权限时，页面会保留登录状态并显示权限提示。

## 患者操作

### 1. 完成本人资料

1. 登录后进入“我的资料”。
2. 填写患者编号、姓名、性别、出生日期和联系电话。
3. 选择是否存在 MRI 禁忌症。
4. 如存在禁忌症，逐条填写类型、说明和严重程度。
5. 保存资料。

后续可在“我的资料”中修改本人信息和禁忌症。禁忌症发生变化后，医生开始检查前会重新获取最新内容。

### 2. 提交检查申请

1. 进入“申请检查”。
2. 填写检查项目、临床诊断和优先级。
3. 点击“提交申请”。
4. 在“我的检查”中查看待检查、检查中、已完成或已出报告状态。

患者提交的申请自动绑定当前登录患者，不需要填写患者编号或内部标识。

### 3. 查看和下载影像

1. 进入“我的影像”。
2. 报告发布前，可查看影像归档进度，但不能打开或下载影像。
3. 报告发布后，点击“查看影像”。
4. 在影像弹窗中点击单张影像的“下载”，或点击“下载全部”保存整个检查的影像压缩包。

如果系统当前关闭影像下载，页面会显示关闭提示，下载按钮不可用。患者下载只限本人已发布报告关联的影像。

### 4. 查看报告

进入“我的报告”查看处理状态。报告发布前不显示影像所见和诊断意见；发布后显示完整内容。

## 医生操作

### 1. 查看患者资料

进入“患者档案”，按姓名或患者编号搜索。医生可查看患者基本资料、MRI 禁忌症和检查历史，但不能新增、修改或删除患者本人资料。

### 2. 创建和修改检查申请

1. 进入“检查申请”。
2. 选择患者，填写检查项目、临床诊断和优先级。
3. 保存后，列表中的“安全风险”显示待评估、无风险、低风险或高风险。
4. 在检查仍为“待检查”时可编辑申请。修改患者或申请内容后，系统重新评估风险并清除旧的高风险确认记录。

系统在保存申请时读取患者当前禁忌症并保存风险摘要。未填写或无法识别的严重程度按高风险处理。

### 3. 安排检查

1. 在“检查排程”中选择待检查申请。
2. 填写检查室、开始时间和技师。
3. 选择 30、45 或 60 分钟检查时长。
4. 点击“新增排程”。

系统同时检查：

- 同一检查室的时间是否重叠；
- 同一技师在不同检查室的时间是否重叠。

冲突检测覆盖全部未取消的检查申请。发生冲突时，页面显示占用该检查室或技师的时间段和检查申请编号，可切换到对应检查申请查看或删除；系统不会覆盖原排程，也不会自动改变时间。前一项结束时间等于后一项开始时间时允许保存。

### 4. 开始和完成检查

1. 在待检查记录上点击“开始”。
2. 系统重新读取患者最新禁忌症。
3. 无风险或低风险时直接开始检查。
4. 高风险时，弹窗显示禁忌症类型、说明和严重程度。
5. 医生完成评估后点击“确认已评估风险并开始检查”。
6. 检查完成后点击“完成”。

高风险确认记录包含当前医生和确认时间。患者禁忌症信息暂时无法读取时，系统不会开始检查。

### 5. 归档和上传影像

1. 检查完成后进入“影像归档”。
2. 选择已完成检查，填写影像描述并保存。
3. 进入“影像管理”，添加序列。
4. 选择序列并上传影像文件。
5. 页面显示真实影像缩略图，可按文件或序列删除。

### 6. 下载影像

1. 在“影像管理”中选择下载用途：诊断查看、会诊、归档导出或其他。
2. 选择“其他”时填写用途说明。
3. 点击影像卡片上的“下载”保存单个原始文件。
4. 点击“下载全部”保存整个检查的影像压缩包。
5. 在“最近下载记录”查看操作人、时间、下载范围和用途。

整组压缩包按影像序列分目录保存，同名文件不会相互覆盖。只有成功读取的单个文件或成功生成的压缩包会写入下载记录。

### 7. 编写和发布报告

1. 进入“诊断报告”，选择已完成检查和对应影像。
2. 填写影像所见和诊断意见。
3. 提交审核。
4. 审核人可通过或驳回。
5. 驳回后可回到草稿修改并重新提交。
6. 审核通过后发布报告。

已发布报告不能再编辑或删除。发布后患者可查看报告正文和关联影像。

## 常见提示

- “患者不存在”：所选患者资料已不存在，请刷新列表后重新选择。
- “仅待检查状态的检查申请可以安排排程”：该检查已经开始、完成或取消。
- “当前检查存在高风险 MRI 禁忌症”：需要医生查看风险明细并明确确认。
- “检查室已安排检查”或“技师已有检查安排”：调整检查室、技师、开始时间或检查时长。
- “诊断报告发布后方可查看影像”：患者需要等待报告发布。
- “当前配置已关闭影像下载”：等待管理配置重新开放下载。
- “登录状态已失效”：重新登录。
- “当前账号没有执行此操作的权限”：返回本人可操作的页面继续使用。

```powershell
npm install
npm run dev
```
