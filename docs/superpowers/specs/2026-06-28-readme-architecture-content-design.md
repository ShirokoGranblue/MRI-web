## 图表设计

图表总数控制在三张：

- 系统架构图：React 前端经 8080 网关访问认证、患者、检查、影像和报告服务；服务使用 Nacos、Redis、MySQL、MinIO，并通过 OpenFeign 交换业务数据。
- 业务闭环图：患者注册和建档，医生处理检查、排程、影像与报告，患者在发布前查看进度、发布后查看报告和影像。
- 状态机图：检查状态和报告状态并列展示，不修改现有业务流转。

Mermaid 节点使用简短中文，端口和服务名在图下方表格中给出，避免图内文字过密。

## 功能说明

功能区分为医生端、患者端和公共能力：

- 医生端：只读患者资料和禁忌症；处理检查申请、排程、检查执行、影像归档与上传、报告编写、审核和发布。
- 患者端：注册、本人建档、禁忌症维护；每 5 秒静默刷新本人检查、影像和报告进度；报告发布后查看正文和影像。
- 公共能力：JWT、401/403 区分、可信身份头、顶部操作提示、Gateway、Nacos、Feign、Redis、MySQL、MinIO 和 Swagger。

检查排程说明必须覆盖具体设备、检查时间、执行人员、设备和时间冲突，以及对状态流转和影像归档的业务支撑。
